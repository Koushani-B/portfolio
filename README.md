# Koushani Biswas — Personal Academic Website

Personal website for Koushani Biswas, PhD Student in Neuroscience at the University of Iowa.

## Hosting

This site is hosted via [GitHub Pages](https://pages.github.com/).

## File structure

```
index.html          ← main page
image-slot.js       ← headshot drag-and-drop component
tweaks-panel.jsx    ← design tweaks panel (React/Babel)
uploads/            ← background imagery (Cajal drawing + neuron art)
.nojekyll           ← disables Jekyll so assets load correctly
```
